# Qard - Networking Industrial Premium

Qard es una sofisticada herramienta de networking diseñada específicamente para consultores de TI y profesionales de ventas industriales de alto nivel. Transforma tu dispositivo en una tarjeta de presentación inteligente y una potente base de datos de contactos premium.

![Qard Interface Mockup](https://images.unsplash.com/photo-1557683316-973673baf926?auto=format&fit=crop&q=80&w=1200)

## 🚀 Características Principales

- **My Qard (QR ID):** Genera tu tarjeta de presentación digital instantáneamente. Intercambia información con un simple escaneo, sin necesidad de tarjetas físicas.
- **Scan & Connect:** Escáner de alta precisión para capturar tarjetas Qard de otros profesionales en eventos y ferias industriales.
- **Network Management:** Una base de datos organizada para gestionar tus contactos estratégicos. Visualiza perfiles detallados y mantén tu red activa.
- **Diseño Premium:** Interfaz minimalista con modo oscuro de alta fidelidad, optimizada para ofrecer una experiencia de usuario fluida y elegante.
- **Guardado en Dispositivo:** Simulación de integración con la agenda de contactos del sistema para una gestión rápida y eficiente.

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5 semántico, Javascript Moderno (ES6+).
- **Estilos:** Vanilla CSS con un sistema de diseño basado en tokens para una consistencia extrema.
- **Iconografía:** [Lucide Icons](https://lucide.dev/) para una estética técnica y limpia.
- **Tipografía:** Inter & Outfit (Google Fonts) para máxima legibilidad.
- **Build Tool:** [Vite](https://vitejs.dev/) para un desarrollo ultrarrápido y optimización de assets.

## 📦 Instalación y Desarrollo

Sigue estos pasos para ejecutar el proyecto localmente:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/qard.git
   cd qard
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

## 🌐 Despliegue

Este proyecto está optimizado para su despliegue en plataformas como **Vercel** o **Netlify**. Asegúrate de:

1. Vincular tu repositorio de GitHub.
2. Configurar el comando de build como `npm run build`.
3. Configurar el directorio de salida (Output Directory) como `dist`.

## 🎨 Design System

Qard utiliza una paleta de colores curada para el sector industrial:
- **Carbon Black:** `#0a0a0a` (Fondo primario)
- **Deep Steel:** `#121212` (Cards y componentes)
- **LinkedIn Blue (Accent):** `#0077b5` (Interacción)
- **Glassmorphism:** Efectos de desenfoque y capas para una sensación de profundidad premium.
